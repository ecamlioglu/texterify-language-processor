# Texterify Renamer 1.1.0

Native menu bar app for renaming files inside Texterify ZIP exports. Requires **macOS 27 or later and Apple Silicon**. No Python installation required.

- Drag a Texterify ZIP onto the menu bar icon or choose a file from the panel.
- Preview renamed files, edit language mappings, and save the output ZIP.
- Open **Tercihler → Güncellemeleri denetle…** to download and install future macOS releases.
- Optional automatic checks notify you inside the panel. Installation and relaunch require your action.

## Install

Download `Texterify-Renamer-1.1.0-arm64.zip`, extract it, move **Texterify Renamer.app** into **Applications**, and open it. The app lives in the menu bar.

This release is Developer ID signed and notarized by Apple. The update feed and update ZIP are independently signed with Sparkle Ed25519 signatures.

If you installed the early 1.0.0 build, quit it and install this version manually once. That early build did not include the updater. Later releases can be installed from within this app. Configuration and preferences retain the same application identity.

`SHA256SUMS.txt` is provided to verify the downloaded ZIP. The Python library has its own releases and is independent of the macOS app.
