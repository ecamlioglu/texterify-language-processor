# Texterify Renamer 1.1.1

Output ZIPs now contain **only files that match your active mappings**.

- Unmapped languages, metadata, and helper files are excluded.
- A warning lists every excluded file before saving and on the saved-result screen.
- Add a mapping and preview again to include a missing file. A mapping may keep the original filename.
- Nested mapped files keep their folder paths and original contents. The source ZIP is never modified.
- If nothing matches, no output is created and the error identifies the unmapped files.

Open **Tercihler → Güncellemeleri denetle…** in 1.1.0 to update, or download `Texterify-Renamer-1.1.1-arm64.zip`, unzip, and move **Texterify Renamer.app** into Applications after quitting the previous copy.

Requires **macOS 27+ and Apple Silicon**. Build 5. Developer ID signed and notarized by Apple; the update feed and archive have Sparkle Ed25519 signatures. The legacy Python tool is unchanged.
