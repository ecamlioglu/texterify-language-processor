# Texterify Renamer wiki

A guide to the native menu bar app, with a separate path for the legacy Python tool. These pages live in the repository so documentation changes can be reviewed and versioned alongside the code.

[Download the Mac app](https://github.com/ecamlioglu/texterify-language-processor/releases/tag/macos-v1.1.0) · [Repository home](../../README.md)

## Use the Mac app

1. [Installation](Installation.md) — requirements, download, first launch.
2. [Daily workflow](Usage.md) — select an export, preview, save.
3. [Configuration](Configuration.md) — mappings, JSON, output naming.
4. [Updates](Updates.md) — manual and optional automatic checks.
5. [Troubleshooting](Troubleshooting.md) — problems and issue reports.

The interface is currently Turkish. Each page uses its actual button labels.

## Use Python instead

[Legacy Python](Legacy-Python.md) covers terminal use and automation, with a link to the complete CLI/API reference. Installing Python is not a step in setting up the Mac app.
